## 🚀 Why MarkFlow? / 为什么选择 MarkFlow?

大多数标注工具只管“画线”，但 MarkFlow 关注的是 **“回顾与索引”** 。我们将碎片化的网页标记转化为**结构化的知识大纲**，让长文阅读从“迷失滚动”变为“精准跳转”。

![MarkFlow Preview](./assets/Highlight-Mark-Flow_4.gif '系统界面预览')

### ✨ 核心亮点

- **📍 书签式精准跳转**：每一处高亮都是一个“锚点”。通过侧边栏点击笔记，瞬间回跳原文位置，找回上下文。
- **📂 自动大纲构建**：智能识别网页 H1-H6 标题，将你的**标记**按章节自动归类，线性碎片瞬间变成逻辑图谱。
- **⚡ 呼吸感交互 (v0.5.1)**：按住 `Alt` 键拖拽即可**高亮**。优化算法彻底杜绝双击、三击误触，标注流程从未如此纯粹。
- **🔐 隐私至上**：100% 本地存储，无需注册，不采集数据，支持一键导出 Markdown 至 Obsidian/Notion。

## 核心技术实现 / Technical Deep Dive

### 1. 物理定位：多层级宿主链与高精度锚点

MarkFlow 专门针对现代 Web 组件（Web Components）进行了定位优化：

- **Shadow DOM 穿透 (宿主链)**: 系统会递归捕获从 Document 到目标元素的所有 Shadow Host，生成形如 `host-a |>>>| host-b` 的物理描述符。恢复时，系统按图索骥，物理递归穿透每一层隔离，将路径解析的“本地根节点”精准送达目标所在的 Shadow Root。
- **高精度锚点 (Level 1)**: 在锁定容器后，利用 Rangy 生成基于节点索引和字符偏移的序列化路径。这是 **首选的极速还原手段**，通过 100% 指纹校验确保在 DOM 结构未变时的绝对准确。

### 2. 夹逼定位法 (Sandwich Anchoring)

为了解决“网页内容被作者修改导致高亮漂移”，我们使用了 **Sandwich Anchoring** 算法。该算法不再迷信单一的文字内容，而是通过“邻居比对”进行纠偏。

#### 核心流程：

1.  **指纹采集**: 高亮创建时，物理采集选区前后各 20 字符作为“左哨兵”和“右哨兵”。采集基于容器内的 `绝对字符偏移量`，而非模糊的全文索引，彻底解决 A/B 交换误判。
2.  **双向夹逼**: 恢复时，系统在页面中进行滑动比对，寻找“左哨兵”和“右哨兵”同时吻合的区域。
3.  **零搜索还原 (Zero-Search Precision)**: 搜索算法会计算高亮片段在父容器内的 **局部绝对偏移坐标 (Local MatchIndex)**。
4.  **结果**: 无论是自动还是手动恢复，系统均直接利用该物理坐标进行“零猜测”还原。**即便中间文字被删减，高亮依然能毫米级锁定残余部分，绝不产生偏移。**

#### 举例说明：

- **原始状态**: `妮好 [corporis inventore aspernatur] laborum amet culpa`
- **内容变更**: 作者删除了中间的 `in`。
- **匹配过程**: 算法发现“左哨兵” (`妮好 `) 和“右哨兵” (` laborum...`) 依然存在。
- **精准对齐**: 系统通过局部坐标锁定锚点，高亮范围自动缩短为 `[corporis ventore aspernatur]`，完美避开前面的“妮好”和后面的内容。

### 3. 四级阶梯恢复架构 (Restoration Flow)

当原始路径失效时，系统启动自动防御机制：

| 层级        | 名称         | 逻辑                   | 自动恢复门槛          | 目的                         |
| :---------- | :----------- | :--------------------- | :-------------------- | :--------------------------- |
| **Level 1** | **完美匹配** | 路径 + 指纹 100% 吻合  | 100%                  | 极速无感恢复，杜绝“移花接木” |
| **Level 2** | **全局优选** | 全文搜索 + 上下文评分  | 唯一项且相似度 >= 85% | 元素位置漂移，但内容本身未变 |
| **Level 3** | **夹逼重构** | **Sandwich Anchoring** | 相似度 >= 95% (竞争)  | 内容微调场景（文字被增删）   |
| **Level 4** | **人工确认** | Disambiguation UI      | 用户交互              | 最终兜底，由用户进行物理校准 |

### 4. 数据一致性保障

- **纯净采集协议**: 遵循“先采集纯净指纹，后包裹标签”的时序逻辑，防止高亮自身的 `<span>` 标签污染元数据。
- **强制持久化**: 后台脚本通过解构赋值强制触发 Vue 响应式更新，确保纠偏结果物理写入磁盘。
- **彻底丢弃**: 针对内容被永久删除的场景，弹窗提供“彻底丢弃”选项，一键抹除失效标注。

## 📖 快速上手 / Quick Start

### 1. 开启高亮 (Highlight)

按住 **`Alt`** (macOS 为 `Option`) 的同时选中文字，即可唤起高亮工具栏。

### 2. 结构化回顾 (Review)

点击浏览器图标开启 **SidePanel (知识浮岛)**。你会看到**标记**已按文章章节自动排版。

### 3. 精准回跳 (Jump)

在侧边栏点击任意笔记，页面将自动滚动至对应位置并闪烁提示。
