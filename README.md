# 🌊 MarkFlow

**More than a highlighter, it's your web content navigator.** **不仅仅是划词高亮，更是你的网页内容导航仪。**

## 🚀 Why MarkFlow? / 为什么选择 MarkFlow?

大多数标注工具只管“画线”，但 MarkFlow 关注的是 **“回顾与索引”** 。我们将碎片化的网页标记转化为**结构化的知识大纲**，让长文阅读从“迷失滚动”变为“精准跳转”。

![MarkFlow Preview](./assets/Highlight-Mark-Flow_4.gif '系统界面预览')

### ✨ 核心亮点

- **📍 书签式精准跳转**：每一处高亮都是一个“锚点”。通过侧边栏点击笔记，瞬间回跳原文位置，找回上下文。
- **📂 自动大纲构建**：智能识别网页 H1-H6 标题，将你的**标记**按章节自动归类，线性碎片瞬间变成逻辑图谱。
- **🌐 跨元素无缝恢复 (v0.5.2)**：突破 DOM 限制，高亮可跨越多个 `<p>`、`<div>` 或列表项。算法自动计算最小公共祖先 (LCA)，确保长文本段落的完整性。
- **🛠️ 进化与自愈机制**：当页面内容发生删减时，通过“歧义弹窗”一次确认，标记即可自动进化（Self-healing）以适配新结构，彻底解决刷新后反复弹窗的烦恼。
- **⚡ 呼吸感交互 (v0.5.1)**：按住 `Alt` 键拖拽即可**高亮**。优化算法彻底杜绝双击、三击误触，标注流程从未如此纯粹。
- **🔐 隐私至上**：100% 本地存储，无需注册，不采集数据，支持一键导出 Markdown 至 Obsidian/Notion。

## 📖 快速上手 / Quick Start

### 1. 开启高亮 (Highlight)

按住 **`Alt`** (macOS 为 `Option`) 的同时选中文字，即可唤起高亮工具栏。

### 2. 结构化回顾 (Review)

点击浏览器图标开启 **SidePanel (知识浮岛)**。你会看到**标记**已按文章章节自动排版。

### 3. 精准回跳 (Jump)

在侧边栏点击任意笔记，页面将自动滚动至对应位置并闪烁提示。

## 技术实现 / Technical Deep Dive

### 1. 物理定位：多层级宿主链与高精度锚点

MarkFlow 专门针对现代 Web 组件（Web Components）进行了定位优化：

- **Shadow DOM 穿透 (宿主链)**: 系统会递归捕获从 Document 到目标元素的所有 Shadow Host，生成形如 `host-a |>>>| host-b` 的物理描述符。恢复时，系统按图索骥，物理递归穿透每一层隔离，将路径解析的“本地根节点”精准送达目标所在的 Shadow Root。
- **高精度锚点 (Level 1)**: 在锁定容器后，利用 Rangy 生成基于节点索引和字符偏移的序列化路径。这是 **首选的极速还原手段**，通过 100% 指纹校验确保在 DOM 结构未变时的绝对准确。

### 2. 多维锚点共识算法 (Consensus Anchoring & Local Alignment)

为了解决“网页内容被大幅增删导致高亮漂移”，MarkFlow 放弃了脆弱的单点索引，采用了 **多维锚点共识 (Multi-Anchor Consensus)** 与 **局部双端对齐 (Local Alignment)** 算法。

#### 核心流程：

1.  **指纹采样**: 高亮创建时，在选区及周围片段中均匀提取多个 12 字符的“指纹锚点”，记录其相对于高亮中心的物理位移。
2.  **共识搜索**: 恢复时，系统在页面中检索所有锚点。即使部分锚点因内容删除而消失，只要有足够比例的锚点达成“空间位置共识 (Spatial Consensus)”，系统即可锁定高亮的大致区域（簇心）。
3.  **局部双端对齐 (Local Alignment)**：在锁定簇心后，算法启动探测。它会模拟选区边界的轻微偏移，计算每一个潜在切片的相似度得分，并引入**长度惩罚因子**。
4.  **结果**: 算法会选择综合得分（内容相似度 + 长度接近度）最高的片段作为最终高亮。**即便中间文字被删减，系统也能智能逼近最优边界，确保恢复后的内容语义完整，不再因为丢字而反复弹窗。**

#### 举例说明：

- **原始状态**: `妮好 [corporis inventore aspernatur] laborum amet culpa`
- **内容变更**: 作者删除了中间的 `t consectetur...`。
- **匹配过程**: 算法通过残存的“妮好”和“125XS...”等多个锚点锁定簇心。
- **边界进化**: 双端对齐算法在簇心周围搜索，发现缩短后的片段相似度最高，自动修正高亮边界。
- **自愈完成**: 系统通过“标记进化”更新数据库，确保下次刷新时能以极速 Level 1 路径无感恢复。

### 3. 四级阶梯恢复架构 (Restoration Flow)

当原始路径失效时，系统启动自动防御机制：

| 层级        | 名称         | 逻辑                   | 自动恢复门槛          | 目的                         |
| :---------- | :----------- | :--------------------- | :-------------------- | :--------------------------- |
| **Level 1** | **路径还原** | Rangy 序列化路径还原   | 相似度 > 95%          | 极速无感恢复，性能最优       |
| **Level 2** | **内容对齐** | 局部/正则精确搜索      | 唯一项且相似度 100%   | 元素位置漂移，但内容未变     |
| **Level 2.5**| **全局回退** | 全文档回退搜索         | 唯一项且相似度 100%   | 解决虚拟列表导致的容器复用   |
| **Level 3** | **共识重构** | **Consensus Search**   | 唯一项且相似度 >= 85% | 内容微调场景（文字被增删）   |
| **Level 4** | **歧义消除** | Disambiguation UI      | 用户手动交互          | 最终兜底，由用户进行物理校准 |

### 4. 极端环境适配 (Bilibili/Reddit/X)

针对无限滚动和复杂 Web 组件页面，系统内置了以下防御机制：

- **3s 恢复冷却**: 当全局搜索失败时，该标记进入 3 秒静默期，防止虚拟列表滚动时产生的循环重试。
- **正则模糊匹配**: 搜索算法自动忽略 `\n`、多空格及**零宽不可见字符 (`\u200b`)**，穿透碎片化的文本节点。
- **迭代式 DOM 遍历**: 放弃递归改用“栈”遍历，轻松吃下万级 DOM 节点而不产生溢出。

### 5. 数据一致性保障

- **纯净采集协议**: 遵循"先采集纯净指纹，后包裹标签"的时序逻辑，防止高亮自身的 `<span>` 标签污染元数据。
- **强制持久化**: 后台脚本通过解构赋值强制触发 Vue 响应式更新，确保纠偏结果物理写入磁盘。
- **彻底丢弃**: 针对内容被永久删除的场景，弹窗提供"彻底丢弃"选项，一键抹除失效标注。
