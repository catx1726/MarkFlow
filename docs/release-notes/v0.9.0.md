# Release Notes — v0.9.0 (2026-09-13)

> 用途：GitHub Release 文案 + AMO/CWS 更新说明源。遵守降调红线（无「智能/精准/瞬间/100%」）。

## 中文版

### 新功能

- **本地备份与恢复**：设置页新增「备份与恢复」区——一键导出全部标记、标签与设置为本地 JSON 文件（不含 GitHub Token，不落任何密钥）；导入时自动校验文件格式，确认后与现有数据**合并**（不丢失已有标记），并恢复设置。不使用 GitHub 同步的用户也有数据保障。
- **首次使用引导**：首次普通划词时，选区旁出现一次性提示「按住 Alt 划词即可标记」；首次打开高亮工具栏时提示 Alt+S（保存）/ Alt+D（删除）快捷键。错过可在设置页点「重新显示」。
- **设置页快捷键速查**：欢迎卡片新增快捷键说明，实时跟随你的自定义值。

### 改进与修复

- 侧边栏：修复折叠动画与吸顶的抖动；标题行多击不再误选；网页标题取首个带标题的标记，旧数据自动回填修复
- 回跳原文时的定位闪烁色统一为品牌琥珀
- 设置/侧边栏质感对齐官网：中性色板、去多余阴影、圆角收敛
- 全站文案按实际实现校准，移除绝对化表述

### 网站（不影响扩展）

- 新增免安装体验页：浏览器直接试用「划词标记 → 侧栏归类 → 回跳原文」完整闭环
- 落地页技术 SEO：中英双语标题品类词、结构化数据、sitemap、hreflang

## English

### New

- **Local backup & restore**: new "Backup & Restore" section in Settings — export all marks, tags and settings to a local JSON file (GitHub Token is never included); import validates the file, then merges with existing data (nothing is lost) and restores settings. No GitHub sync needed to keep your data safe.
- **First-use tips**: a one-time hint near your first selection shows the Alt+drag gesture; the first toolbar opening shows the Alt+S / Alt+D shortcuts. Re-show both from Settings.
- **Shortcuts reference** on the Settings welcome card, following your custom keys.

### Fixes & improvements

- Side panel: no more jitter in collapse animation and sticky headers; title row no longer selects on multi-click; page titles self-heal from older data
- Jump-back flash color unified to brand amber
- Settings/side panel visual polish aligned with the website
- Copy calibrated to actual behavior across the product
