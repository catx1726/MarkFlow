02 / FEATURES

Mark as you read

Hold Alt, select text, pick a color. You never leave the page.

Precise jump-back

Every note records its source position. One click jumps back; the spot is marked by a flash.

Tags & export

Marks are grouped by chapter and filterable by tag. Export to Markdown, or sync across devices via GitHub Gist.

Data stays local. No account. No upload.
