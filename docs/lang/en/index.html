MarkFlow
Web Highlighter with Precise Jump-Back

Hold Alt to highlight any text, then click a note in the Side Panel to jump back to the exact spot. Highlights are auto-grouped by section — add tags to build a knowledge graph across pages.

* 100% local storage, no sign-up required; optional GitHub Gist sync across devices, privacy under your control.

Core Features

Why MarkFlow?

🏷️

Tag-Based Knowledge Management

Tag highlights across pages by topic or project to build your personal knowledge graph. A three-level tree Side Panel (tags → pages → highlights) keeps scattered info neatly organized.

🔗

Bookmark-Style Precise Jump-Back

Every highlight is an anchor. One click in the Side Panel takes you right back to the original spot — no more scrolling around hunting for that key passage.

📑

Smart Outlines & Sorting

Automatically parses article headings into a table of contents, orders highlights by reading sequence, and pins your most recently active pages to the top.

🌐

Adaptive Recovery

Page structure drift or container reuse? MarkFlow tries to auto-repair. If content is substantially changed or the layout is rebuilt, it keeps the context in the Side Panel for you to confirm.

📤

One-Click Markdown Export

Export by tag or by page to Markdown, with a zero-hierarchy-intrusion format that drops perfectly into Obsidian, Notion, and other note-taking tools.

🔄

Multi-Device Sync via GitHub Gist

Sync your data across browsers with a private Gist. First connect pulls and merges before writing, so empty local data never overwrites the cloud; a Tombstone mechanism ensures deletions sync reliably too.

🛡️

Local-First Security

No tracking, no uploads — 100% of your data stays on your device, with no sign-up or login required. Your token lives only in the extension's private storage.

FAQ

Q: How do I start highlighting quickly?

A: Hold Alt (Option on Mac) and drag or click to select text — the color picker pops right up.

Q: How does the tag system work? Can one highlight have multiple tags?

A: After highlighting, click "Add Tag" in the floating toolbar to attach tags. A highlight can belong to multiple tags and will appear under each corresponding tag folder. Untagged highlights go to the "Inbox" by default.

Q: Can I export my data?

A: Absolutely. MarkFlow exports by tag or by page to Markdown in one click, with a zero-hierarchy-intrusion design that fits seamlessly into Obsidian, Notion, and other note tools.

Q: Will my highlights get lost on dynamic pages like YouTube or Reddit?

A: For common cases like page structure drift or container reuse, MarkFlow tries to auto-recover. If the page content is substantially changed or the layout is rebuilt, automatic recovery may not be possible — in that case, the context is kept in the Side Panel for you to confirm.

Q: Can I sync data across devices?

A: Yes. Configure a GitHub Personal Access Token (gist scope only) in the settings page to sync across devices via a private Gist. The first connection automatically pulls and merges remote data, so your cloud data is never overwritten.
