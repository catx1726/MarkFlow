MarkFlow

A web text marker.

Hold Alt and select text to mark it.
Click a note in the side panel — the page jumps back to the marked spot.

02 / USAGE

  1. 1

    Hold Alt, select a passage, pick a color, jot a thought.

    You never leave the page.

  2. 2

    Keep reading. Marks line up by chapter in the side panel.

    Filterable by tag.

  3. 3

    Click a note to return to the marked spot.

    The spot is marked by a flash.

  4. 4

    Export to Markdown, or sync across devices via GitHub Gist.

Data stays local. No account. No upload by default.
