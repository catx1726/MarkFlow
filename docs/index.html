快速上手

如呼吸般自然的交互体验

1

划词高亮

按住 Alt 键（macOS 为 Option）并选中文字，即可唤起高亮工具栏。

2

添加标签

在浮动工具栏中为标记关联标签，构建你的知识分类体系。未归类的标记自动进入收集箱。

3

结构化回顾

点击浏览器图标开启 SidePanel ，笔记按标签 → 网页 → 章节自动排版，阅读顺序与标记顺序一致。

4

精准回跳

在侧边栏点击任意笔记，页面将自动跳转至对应位置，并伴有视觉闪烁提示。

常见问题

Q: 如何快速开始标记？

A: 按住键盘上的 Alt 键（Mac为Option）并拖拽或者点击选中文字即可弹出颜色选择栏。

Q: 标签系统怎么用？一个标记可以打多个标签吗？

A: 高亮后在浮动工具栏中点击"添加标签"即可关联。一个标记可以属于多个标签，它会出现在每个对应的标签文件夹下。未打标签的标记默认存放在"收集箱"中。

Q: 数据可以导出吗？

A: 当然可以。MarkFlow 支持按标签或按网页一键导出为 Markdown 格式，零层级入侵设计可无缝嵌入 Obsidian、Notion 等笔记工具。

Q: 我的高亮在哔哩哔哩/Reddit 等动态页面会丢失吗？

A: 页面结构漂移、容器复用等常见场景下，系统会尝试自动恢复。若页面内容发生实质性增删或布局重构，可能无法自动恢复，此时会在侧边栏保留上下文供你确认。

Q: 数据可以跨设备同步吗？

A: 可以。在设置页配置 GitHub Personal Access Token（仅需 gist 权限），即可通过私有 Gist 在多台设备间同步。首次连接会自动拉取并合并远程数据，不会覆盖云端。
