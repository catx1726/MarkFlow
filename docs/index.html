02 / 功能

划词标记

按住 Alt 选中文字，选择颜色。不需要离开当前页面。

精准回跳

每条笔记记录原文位置。点击即跳转，位置以闪烁标出。

标签与导出

标记按章节归类，可按标签筛选。支持导出 Markdown，支持经 GitHub Gist 多端同步。

数据保存在本地。不需要账号。不上传。

03 / 使用

  1. 1

    按住 Alt，选中文字。

  2. 2

    选择颜色，或添加标签。

  3. 3

    继续阅读。标记按章节排列在侧边栏。

  4. 4

    点击侧边栏中的笔记，回到原文位置。
