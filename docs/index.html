MarkFlow
你的网页内容导航仪

不仅仅是高亮。MarkFlow 将你的每一次 “标记” 转化为可索引的 “精准锚点” ，构建 结构化大纲 ，让你在网页中瞬间找回上下文。

* 100% 本地存储，无需注册，隐私第一。

核心特性

为什么选择 MarkFlow?

🔗

书签式精准跳转

每一处标记都是一个锚点。侧边栏一键跳转，原文自动定位，再也不用手动翻找网页重点。

📑

智能大纲构建

自动解析文章标题层级，将碎片笔记组织成清晰的结构化目录，阅读深度一目了然。

🛡️

极致本地安全

不采集、不上传，数据 100% 留存在你的设备中。

快速上手

如呼吸般自然的交互体验

1

划词高亮

按住 Alt 键（macOS 为 Option）并选中文字，即可唤起高亮工具栏。

2

结构化回顾

点击浏览器图标开启 SidePanel (知识浮岛) ，你的笔记将按文章章节标题自动排版。

3

精准回跳

在侧边栏点击任意笔记，页面将自动跳转至对应位置，并伴有视觉闪烁提示。

常见问题

Q: 如何快速开始标记？

A: 按住键盘上的 Alt 键（Mac为Option）并拖拽或者点击选中文字即可弹出颜色选择栏。

Q: 数据可以导出吗？

A: 当然可以。MarkFlow 支持一键导出当前页或全部笔记为 Markdown 格式，完美适配 Obsidian 和 Notion。
