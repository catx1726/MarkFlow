## 5. 暂不执行 (Wontfix/Later)

- **数据压缩 (Gzip)**: 会导致 Gist 网页端数据不可读，优先通过“数据精简”和“分片存储”解决容量问题。
- **GitHub API Rate Limit 监控**: 目前同步频率极低，监控成本大于收益。
- **自动聚类算法增强 (TF-IDF)**: 属于重量级特性。在用户量级上升前，手动标签系统已经足够。
