# MarkFlow v0.8.0 发布说明

**发布日期**: 2026-08-20

---

### ✨ 新增功能

- **英文国际化（i18n）** (#68)
  - 全部界面文案双语化（中文 / English），覆盖 Popup、侧边栏、设置页、划词面板、歧义弹窗等 158 处文案。
  - 设置页新增「通用设置 → 界面语言」选项：**跟随浏览器 / 中文 / English**，切换即时生效、全界面重渲染。
  - 默认跟随浏览器界面语言：中文用户看到中文，其他语言用户自动看到英文。
  - 扩展名称与描述接入 `_locales`，商店列表与扩展管理页双语展示。
  - 技术架构：TS 字典 + 类型强制中英同构（缺翻译直接编译报错），为后续更多语言打好基础。

- **Tooltip 智能定位 2.0：鼠标感知** (#62, #67)
  - 划词后，Tooltip 不再遮挡选中文本：正向划选出现在选区下方、反向划选出现在上方，且**水平方向跟随鼠标**——既保护原文可见，又落在手边。
  - 点击已有标记时，Tooltip 以 context-menu 方式出现在点击处下方（长标记不再"跑偏"到标记开头）。
  - 定位基于实际渲染高度（取代硬编码），标签再多也不会溢出视口。

- **Tooltip 支持拖拽** (#62)
  - 按住顶部栏即可拖动 Tooltip 到任意位置（视口内钳制），写长备注时可挪开对照原文。

- **侧边栏视觉精修** (#65, #72, #75, #76, #77, #78)
  - 层级减负：标签夹内容区由"盒子套盒子"改为**缩进 + 引导线**，视觉噪音减半，长列表更清爽。
  - 微交互：文件夹/网页/章节三级展开收起均有丝滑高度动画；Tooltip 弹出带轻微上浮动效。
  - **四级吸顶**：搜索栏 → 标签夹 → 网页标题 → 章节大纲依次堆叠吸顶（iOS 通讯录式），任何长列表滚动都始终知道自己在哪个标签、哪个网页、哪个章节；吸顶零跳变、零穿透。
  - 卡片层级统一：常驻卡片零阴影 + 细边线，阴影只保留给浮层（菜单/弹窗）。
  - 细节：标记/网页/章节组/标签夹的⋯菜单在页面底部时自动**向上弹出**，不再被底边截断；长标题自动省略号截断，不再挤出数量统计。

- **主题手动切换** (#71)
  - 设置页「通用设置」新增主题选项：**跟随系统 / 浅色 / 深色**，切换后所有界面（含划词 Tooltip）实时生效，重启不闪屏。

- **网页级标记计数** (#74)
  - 侧边栏网页标题新增 `(n)` 计数，信息层级完整：pill 徽章（标签）→ 标题+计数（网页）→ 缩进+计数（章节）。

### 🐛 问题修复

- **修复 rangy 类型声明误导导致的 Tooltip 无法弹出** (#62)
  - `@types/rangy` 声明 `RangyRange extends Range`，但运行时并未实现 `getBoundingClientRect()`，调用即抛错导致 Tooltip 静默不弹出。
  - 新增 `getRangyRangeRect()` 经 `nativeRange` 获取真实选区位置，兼容原生 Range，附带回归测试。

- **修复侧边栏滚动时内容穿透标题/搜索栏** (#65)
  - 吸顶头部补充不透明背景，浅色模式下尤为明显。

- **修复 ⋯ 下拉菜单被动画容器裁剪** (#65)
  - 折叠动画的裁剪样式改为仅在动画进行期间生效，菜单弹出自如。

- **修复浅色模式视觉材质不统一** (#65)
  - 标签夹行统一为白卡片 + 细边线，引导线与卡片边线同发色，灰色不再各自为政。

### 🎨 品牌焕新

- **品牌色统一为琥珀橙（Amber）** (#62)
  - 从荧光笔的隐喻出发：品牌色与高亮内容色同族，看到界面色即联想到"高亮"。
  - 扩展 UI、宣传页、扩展图标全部统一；主按钮采用琥珀底 + 深色字，对比度达 8.4:1（WCAG AA 以上）。
  - 宣传页新增社交分享卡片（OG/Twitter Card）——链接贴到 Reddit/微信/Telegram 时显示品牌预览图。 (#64)
  - **宣传页英文版上线**：`flow.soulboy.site/lang/en/`，与中英双向切换链接。 (#70)

### 🏗️ 工程质量

- 新增 34 个单元测试（定位算法 22 个 + i18n 6 个 + 主题/菜单翻向 6 个），定位逻辑纯函数化并覆盖鼠标感知各分支。
- 设置页板块按使用频率重排：GitHub 同步前移、错误日志沉底；页面标题同步双语；侧边栏间距细节微调。
- 修复 vitest setupFiles 未提交导致的 main 分支测试崩溃；修复 lint-staged 存量阻塞项，提交管线恢复强制力。
